## 대사 — YUNA1.DAT
- 0x8000(32 KB) 블록 26개. 블록 머리 u16 2개(**리틀 엔디안**: 0x1C5A, 0x09BF …) — 유나 3 의 [코드 길이 A][문자열 길이 B] 와 같은 꼴로 보임(⏳확인).
- 문자열 = Shift-JIS, 00 끝. 앞에 한 글자 머리(«B»·«7»·«3» 등 — 화자/얼굴 코드로 보임), 전각 공백으로 띄어 씀.

## 대사 블록 구조 (2026-10-01 확정)
- 블록 머리 u16 LE 4개: **A**(코드 길이) · **B**(문자열 길이) · **C**(대사 번호표 바이트) · E(0x1052 등, 미상).
- 코드 = +8? ‥ A+2(유나 3 dat.Block 과 같은 명령 형식 — 25/26 블록 해석, 0x58000 은 A+2 에서 안 끝남 ⏳) · 문자열 S=A+6, 길이 B(변수·파일 이름 «A_1.ACM» 등) ·
  **대사 번호표** T=S+B, u16 LE × C/2(대사 기준 M=T+C 에서의 바이트 오프셋) · **대사** = SJIS 00 끝, 앞에 화자 머리 한 글자(«2»·«B»·«7»·«3» — 없는 것도 있음), 줄바꿈 0x0A, 띄어쓰기 = 전각 공백.
- 블록마다 빈 곳 16 KB 이상 → 새 대사는 대사 끝 뒤에 덧붙이고 번호표 값만 바꾼다(코드는 대사를 «번호»로 부름).
- 글꼴 칸 = (구−1)×94 + (점−1) — JIS 순 그대로(«あ» 283, «亜» 1410 확인). 한글 음절 → 게임이 안 쓰는 2수준 한자(E8xx‥, 476칸+, 더 필요하면 다른 행) 칸.
